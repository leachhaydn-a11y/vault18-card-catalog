# Lorcana Collection

Welcome to the Lorcana section of your card catalog!

## Overview

This section tracks your Disney Lorcana Trading Card Game collection including:
- Set information
- Card inventory
- Storage locations
- Condition and valuation notes

## Getting Started

- Add your sets and cards
- Document storage locations
- Track card conditions
- Organize by character or story

## Sets

Add documentation for each set you own. Include:
- Set name and release year
- Number of cards in collection
- Notable character cards
- Storage location
